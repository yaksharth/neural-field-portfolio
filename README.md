# Neural Field

An authored portfolio for an independent AI systems engineer. The site pairs a warm editorial surface with darker working studies so the work feels considered, tactile, and technically credible.

## Included studies

- `/field` — geospatial intelligence console for reasoning across imperfect signals.
- `/learn` — adaptive curriculum that changes with evidence of understanding.
- `/studio` — generative media control surface for directing rhythm, reference, and restraint.

## Run locally

```bash
pnpm install
pnpm --filter @workspace/ai-engineer-portfolio run dev
```

The app is intentionally frontend-only: all interactions use local state so the studies remain explorable without a service dependency.
